## Background
This is a python based initiative tracker for role playing games that takes the following traits about combatants.

* Name
* Number of Actions
* Initiative Roll
* Initiative points between actions
* Speed (to help you decide how to break ties)

It then allows you to progress through a battle as your players take their actions.

## Requirements
You must install Python 3.x to run this program.

## Install

Download all files to your system.
Execute the main script in python.
Example:

python3 /directory/main.py
